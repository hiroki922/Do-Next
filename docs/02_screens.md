# 画面設計

## 画面一覧

| 画面 | URL | 説明 |
|------|-----|------|
| ログイン / 新規登録 | `/` (未認証時) | 認証画面 |
| Todoリスト | `/` (認証後) | タスク一覧・作成・フィルター |
| カンバンボード | ボードタブ | ステータス別カラム表示 |
| カレンダー | カレンダータブ | 期限日・祝日表示 |
| 統計 | 統計タブ | 完了率・集計グラフ |
| 設定 | 設定タブ | パスワード変更 |

---

## 1. ログイン / 新規登録

![ログイン画面](screenshots/01_auth.png)

### 機能
- メールアドレス・パスワードでログイン
- 新規登録（登録後に個人リストを自動作成）
- ログイン / 新規登録をタブで切り替え

---

## 2. Todoリスト

![Todoリスト](screenshots/02_todo_list.png)

### 機能
- 左サイドバー：リスト一覧（個人リスト・共有リスト）・メンバー管理
- フィルターバー：キーワード検索・ステータス・優先度・タグ・期限切れ・並び替え
- 「＋ 新規タスク」ボタンでモーダルを開いてタスク作成
- タスクカード：ステータスバッジ・優先度バッジ・期限日・タグ・サブタスク数
- 一括操作：選択チェックボックス・一括完了・一括削除・一括アーカイブ
- ページネーション

### タスク作成モーダル

![タスク作成モーダル](screenshots/03_create_modal.png)

- タイトル・説明・メモ
- 優先度・期限日・期限時刻・繰り返し設定
- タグ選択

---

## 3. カンバンボード

![カンバンボード](screenshots/04_kanban.png)

### 機能
- 3カラム構成：未着手 / 進行中 / 完了
- ドラッグ&ドロップでカード移動 → ステータス即時更新（API同期）
- ドロップ先カラムのハイライト表示
- タスクカードをクリックして詳細表示

---

## 4. カレンダー

![カレンダー](screenshots/05_calendar.png)

### 機能
- 月カレンダー表示（前月・翌月ナビゲーション）
- 期限日のあるタスクを該当日にチップ表示
- 日本の祝日表示（赤字）
  - 固定祝日・ハッピーマンデー・春分/秋分・振替休日 に対応
- タスクチップをクリックして詳細表示

---

## 5. 統計

![統計](screenshots/06_stats.png)

### 機能
- サマリーカード：総タスク数・完了数・完了率・期限切れ数
- 期間フィルター（7日・30日・90日・全期間）
- 優先度別グラフ
- タグ別グラフ
- 日別完了トレンド

---

## 6. 設定

![設定](screenshots/07_settings.png)

### 機能
- パスワード変更（現在のパスワード・新しいパスワード）

---

## 共通UI

### サイドバー
- リスト一覧の表示・切り替え
- 新規リスト作成
- リスト名の編集・削除
- メンバー管理（招待・ロール変更・削除）
- 折りたたみ・リサイズ対応

### ヘッダー
- ページナビゲーション（Todo / ボード / カレンダー / 統計 / 設定）
- タグ管理ボタン
- ログアウトボタン
- 期限通知（ブラウザ通知）の許可ボタン
