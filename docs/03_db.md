# DB設計

## ER図（概略）

```
users
  ├── tags (1:N)
  ├── lists (1:N, owner)
  │     └── todos (1:N)
  │           ├── sub_tasks (1:N)
  │           ├── attachments (1:N)
  │           ├── comments (1:N)
  │           ├── activity_logs (1:N)
  │           └── todo_tags (N:M) ── tags
  ├── list_members (N:M) ── lists
  └── refresh_tokens (1:N)
```

---

## テーブル定義

### users（ユーザー）

| カラム | 型 | 制約 | 説明 |
|--------|-----|------|------|
| id | INTEGER | PK, INDEX | ユーザーID |
| email | VARCHAR(255) | UNIQUE, NOT NULL, INDEX | メールアドレス |
| hashed_password | VARCHAR(255) | NOT NULL | ハッシュ化パスワード |
| created_at | DATETIME | DEFAULT NOW() | 作成日時 |

---

### lists（リスト）

| カラム | 型 | 制約 | 説明 |
|--------|-----|------|------|
| id | INTEGER | PK, INDEX | リストID |
| name | VARCHAR(255) | NOT NULL | リスト名 |
| owner_id | INTEGER | FK(users.id) CASCADE | オーナーユーザーID |
| created_at | DATETIME | DEFAULT NOW() | 作成日時 |

---

### list_members（リストメンバー 中間テーブル）

| カラム | 型 | 制約 | 説明 |
|--------|-----|------|------|
| list_id | INTEGER | PK, FK(lists.id) CASCADE | リストID |
| user_id | INTEGER | PK, FK(users.id) CASCADE | ユーザーID |
| role | VARCHAR(20) | NOT NULL, DEFAULT 'editor' | ロール（owner / editor） |

---

### tags（タグ）

| カラム | 型 | 制約 | 説明 |
|--------|-----|------|------|
| id | INTEGER | PK, INDEX | タグID |
| name | VARCHAR(100) | NOT NULL | タグ名 |
| color | VARCHAR(7) | NULL | カラーコード（例: #3b82f6） |
| user_id | INTEGER | FK(users.id) CASCADE | 所有ユーザーID |
| created_at | DATETIME | DEFAULT NOW() | 作成日時 |

---

### todos（タスク）

| カラム | 型 | 制約 | 説明 |
|--------|-----|------|------|
| id | INTEGER | PK, INDEX | タスクID |
| title | VARCHAR(255) | NOT NULL | タイトル |
| description | VARCHAR(1000) | NULL | 説明 |
| notes | TEXT | NULL | メモ（長文） |
| completed | BOOLEAN | DEFAULT false | 完了フラグ |
| archived | BOOLEAN | DEFAULT false | アーカイブフラグ |
| priority | ENUM | NOT NULL, DEFAULT 'medium' | 優先度（low / medium / high） |
| due_date | DATE | NULL | 期限日 |
| due_time | VARCHAR(5) | NULL | 期限時刻（HH:MM形式） |
| recurrence | ENUM | NOT NULL, DEFAULT 'none' | 繰り返し（none / daily / weekly / monthly） |
| recurrence_end_date | DATE | NULL | 繰り返し終了日 |
| status | ENUM | NOT NULL, DEFAULT 'todo' | ステータス（todo / in_progress / done） |
| position | INTEGER | NULL | 手動並び替え順 |
| assignee_id | INTEGER | FK(users.id) SET NULL | 担当者ユーザーID |
| list_id | INTEGER | FK(lists.id) CASCADE | 所属リストID |
| created_at | DATETIME | DEFAULT NOW() | 作成日時 |
| updated_at | DATETIME | DEFAULT NOW(), ON UPDATE NOW() | 更新日時 |

---

### todo_tags（タスク-タグ 中間テーブル）

| カラム | 型 | 制約 | 説明 |
|--------|-----|------|------|
| todo_id | INTEGER | PK, FK(todos.id) CASCADE | タスクID |
| tag_id | INTEGER | PK, FK(tags.id) CASCADE | タグID |

---

### sub_tasks（サブタスク）

| カラム | 型 | 制約 | 説明 |
|--------|-----|------|------|
| id | INTEGER | PK, INDEX | サブタスクID |
| todo_id | INTEGER | FK(todos.id) CASCADE | 親タスクID |
| title | VARCHAR(500) | NOT NULL | タイトル |
| completed | BOOLEAN | DEFAULT false | 完了フラグ |
| created_at | DATETIME | DEFAULT NOW() | 作成日時 |

---

### attachments（添付ファイル）

| カラム | 型 | 制約 | 説明 |
|--------|-----|------|------|
| id | INTEGER | PK, INDEX | 添付ファイルID |
| todo_id | INTEGER | FK(todos.id) CASCADE | タスクID |
| filename | VARCHAR(500) | NOT NULL | ファイル名 |
| stored_path | VARCHAR(1000) | NOT NULL | サーバー上の保存パス |
| content_type | VARCHAR(200) | NOT NULL | MIMEタイプ |
| size | BIGINT | NOT NULL | ファイルサイズ（バイト） |
| created_at | DATETIME | DEFAULT NOW() | 作成日時 |

---

### comments（コメント）

| カラム | 型 | 制約 | 説明 |
|--------|-----|------|------|
| id | INTEGER | PK, INDEX | コメントID |
| todo_id | INTEGER | FK(todos.id) CASCADE | タスクID |
| user_id | INTEGER | FK(users.id) CASCADE | 投稿ユーザーID |
| content | TEXT | NOT NULL | コメント本文 |
| created_at | DATETIME | DEFAULT NOW() | 作成日時 |

---

### activity_logs（アクティビティログ）

| カラム | 型 | 制約 | 説明 |
|--------|-----|------|------|
| id | INTEGER | PK, INDEX | ログID |
| todo_id | INTEGER | FK(todos.id) CASCADE | タスクID |
| user_id | INTEGER | FK(users.id) CASCADE | 操作ユーザーID |
| action | VARCHAR(50) | NOT NULL | 操作種別（created / updated / completed / archived / commented） |
| detail | VARCHAR(500) | NULL | 詳細情報 |
| created_at | DATETIME | DEFAULT NOW() | 作成日時 |

---

### refresh_tokens（リフレッシュトークン）

| カラム | 型 | 制約 | 説明 |
|--------|-----|------|------|
| id | INTEGER | PK, INDEX | トークンID |
| user_id | INTEGER | FK(users.id) CASCADE | ユーザーID |
| token | VARCHAR(500) | UNIQUE, NOT NULL, INDEX | トークン文字列 |
| expires_at | DATETIME | NOT NULL | 有効期限 |
| created_at | DATETIME | DEFAULT NOW() | 作成日時 |
