# システム概要

## アプリケーション名

**Do-Next** — フルスタック タスク管理アプリ

## 目的

個人・チームのタスクを効率的に管理するWebアプリケーション。
ステータス管理・カンバンボード・カレンダー連携により、タスクの進捗を多角的に把握できる。

## 技術スタック

| レイヤー | 技術 |
|---------|------|
| バックエンド | Python 3.11 / FastAPI / SQLAlchemy 2.0 / Pydantic v2 |
| データベース | PostgreSQL 16 |
| 認証 | JWT（アクセストークン + リフレッシュトークン） |
| フロントエンド | React 18 / Vite |
| インフラ | Docker / Docker Compose |

## 機能一覧

### 認証
- ユーザー登録・ログイン・ログアウト
- JWTアクセストークン（短期） + リフレッシュトークン（長期）による認証
- パスワード変更

### タスク管理（Todo）
- タスクの作成・編集・削除・複製
- 3段階ステータス：未着手 / 進行中 / 完了
- 優先度：低 / 中 / 高
- 期限日・期限時刻の設定
- 繰り返し設定：なし / 毎日 / 毎週 / 毎月
- メモ（長文テキスト）
- サブタスク管理
- コメント・アクティビティログ
- 添付ファイル
- タグ（複数付与・カラー設定）
- 担当者アサイン
- アーカイブ・一括操作（完了・削除・アーカイブ）

### 表示・フィルター
- キーワード検索
- ステータス・優先度・タグ・期限切れでフィルター
- 並び替え（作成日・期限日・優先度・手動順）
- ページネーション

### ビュー
- **リストビュー** — タスク一覧（デフォルト）
- **カンバンボード** — ステータス別カラム表示・ドラッグ&ドロップで移動
- **カレンダービュー** — 期限日・日本の祝日表示

### リスト・メンバー管理
- 個人リスト・共有リストの作成
- メンバー招待（オーナー / 編集者）

### 統計
- 完了率・優先度別集計・タグ別集計・完了トレンド
